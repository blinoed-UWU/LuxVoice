## Что осталось

1. **Тесты: 72 теста, 13 не проходят.** Все сбои — в самих тестах,
   а не в проекте. Причины выяснены:
   - матчер намеренно пропускает команды **без действий** (заготовки),
     а в тестах команды создавались пустыми → нужно добавить действие;
   - неверные имена в тестах: `all_commands()` вместо `commands()`,
     `rebuild()` вместо `refresh()`, `executor.run()` вместо `execute()`,
     `manager.pack_commands()` — нужно найти настоящее имя;
   - разделы схемы называются `speech_output`, `voice_input`, `general` —
     а не `tts`, `stt`, как я предполагал в тестах;
   - `schema.BOOL` не подставляется как `self.schema.BOOL` в одном тесте;
   - у настройки `stt.wake_sound_volume` нет подсказки — тест требует её
     у всех настроек; либо добавить подсказку, либо ослабить тест.

2. **Один настоящий пробел в коде:** в таблице клавиш нет модификатора
   «контрол» (есть только `ctrl`, `control`). Нужно добавить алиасы
   `контрол`, `шифт`, `альт`, `вин` в `luxvoice/sysint/uinput.py`.

3. **Не проверено вживую** (нужен реальный графический сеанс):
   - запуск полного окна с показом на экране;
   - аватар поверх окон на Wayland;
   - Telegram-бот — `api.telegram.org` недоступен из текущей сети,
     нужен VPN для проверки;
   - работа с ключом нейросети.

4. **Не сделано:** запуск через `./install.sh` целиком (скрипт написан,
   по шагам не прогонялся), установка RHVoice/eSpeak (нужен пароль root),
   английская модель Vosk (не загружена).

## Требуется от пользователя

```bash
# доступ к управлению клавишами и мышью (один раз)
sudo usermod -aG input $USER
# затем выйти из системы и войти заново

# необязательно: голоса получше
sudo pacman -S rhvoice rhvoice-language-russian espeak-ng brightnessctl
```

## Как продолжить

```bash
cd ~/Проекты/LuxVoice
./run.sh --diagnose          # состояние компонентов
.venv/bin/python tests/test_luxvoice.py   # тесты
./run.sh                     # графический интерфейс
```

Ключи API не запрашиваются в переписке — только в интерфейсе программы:
Настройки → ИИ-провайдер.
