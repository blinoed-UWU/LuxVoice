# 🪟 Установка LuxVoice на Windows

## Системные требования

- **Windows**: 10 (версия 1809+) или 11
- **Python**: 3.10 или выше
- **RAM**: 4+ ГБ
- **Микрофон**: любой совместимый с Windows

---

## Шаг 1: Установка Python

1. Скачайте Python с [python.org](https://www.python.org/downloads/)
2. При установке **ОБЯЗАТЕЛЬНО** отметьте галочку **"Add Python to PATH"**
3. Проверьте установку:
   ```cmd
   python --version
   ```
   Должно показать: `Python 3.10.x` или выше

---

## Шаг 2: Установка LuxVoice

### Автоматическая установка (рекомендуется)

1. Откройте **Командную строку** (Win+R → `cmd` → Enter)
2. Перейдите в папку с LuxVoice:
   ```cmd
   cd путь\к\LuxVoice
   ```
3. Запустите установщик:
   ```cmd
   install.bat
   ```

Установщик создаст виртуальное окружение и установит все зависимости.

### Ручная установка

Если автоматическая установка не сработала:

```cmd
cd путь\к\LuxVoice
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-windows.txt
```

---

## Шаг 3: Запуск

```cmd
run.bat
```

Или с параметрами:
```cmd
run.bat --diagnose          # Проверить компоненты
run.bat --command "привет"  # Выполнить команду и выйти
```

## Настройка нейросети

### Вариант 1: LM Studio (локальная, без интернета)

1. Скачайте [LM Studio](https://lmstudio.ai/)
2. Установите и запустите
3. Скачайте модель (рекомендуется: `qwen2.5-7b-instruct-q4_k_m`)
4. Включите **Local Server** (порт 1234)
5. В LuxVoice:
   - Настройки → ИИ-провайдер
   - Провайдер: **LM Studio**
   - Нажмите "Проверить подключение"

### Вариант 2: OpenAI (облачная)

1. Получите API ключ на [platform.openai.com](https://platform.openai.com/api-keys)
2. В LuxVoice:
   - Настройки → ИИ-провайдер
   - Провайдер: **OpenAI**
   - Вставьте API ключ
   - Модель: `gpt-4o-mini`

## Решение проблем

### "Python не найден"
- Убедитесь, что Python добавлен в PATH
- Переустановите Python с галочкой "Add Python to PATH"

### "Не удалось установить зависимости"
```cmd
.venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements-windows.txt
```

### "Микрофон не работает"
1. Проверьте микрофон в **Параметры Windows → Система → Звук**
2. Убедитесь, что микрофон выбран по умолчанию
3. В LuxVoice: Настройки → Голосовой ввод → Выберите устройство

### "Нейросеть не отвечает"
1. Убедитесь, что LM Studio запущен и сервер включен
2. Проверьте подключение: Настройки → ИИ-провайдер → "Проверить подключение"
3. Посмотрите логи: `logs\luxvoice.log`

### "Клавиши не нажимаются"
- Windows требует прав администратора для эмуляции ввода
- Запустите `run.bat` от имени администратора

### "Окна не управляются"
- Некоторые UWP-приложения (из Microsoft Store) не поддерживают управление окнами
- Используйте Win32-приложения вместо UWP

## Отличия от Linux версии

| Функция | Linux | Windows |
|---------|-------|---------|
| Виртуальный ввод | uinput (ядро) | pyautogui |
| Управление окнами | wmctrl/xdotool | pygetwindow |
| Громкость | pactl/wpctl | pycaw |
| Буфер обмена | xclip/wl-paste | pyperclip |
| Скриншоты | scrot/gnome-screenshot | Pillow |
| Питание | systemctl | Windows API |

### Ограничения Windows

- ⚠️ **UWP-приложения** (из Microsoft Store) не полностью поддерживаются
- ⚠️ **Антивирусы** могут блокировать эмуляцию ввода (добавьте в исключения)
- ⚠️ **Права администратора** требуются для некоторых операций

## Удаление

```cmd
cd путь\к\LuxVoice
rd /s /q .venv
```

Это удалит виртуальное окружение. Исходный код можно удалить вручную.
