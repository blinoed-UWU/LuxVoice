# Реализованные улучшения LuxVoice

## ✅ 1. Настраиваемая пауза тишины (silence_timeout)

**Файлы:**
- `luxvoice/core/schema.py` - настройка `stt.silence_timeout`
- `luxvoice/stt/capture.py` - применение параметра
- `luxvoice/stt/recognizer.py` - чтение из настроек

**Описание:**
Пользователь может настроить длительность паузы тишины, после которой система считает фразу завершённой и начинает распознавание.

- **По умолчанию:** 0.9 секунды
- **Диапазон:** 0.3 - 5.0 секунд
- **Раздел настроек:** "Голосовой ввод" → "Распознавание речи"

**Пример использования:**
```python
# В настройках можно изменить:
stt.silence_timeout = 1.5  # для более медленной речи
```

## ✅ 2. Голосовая обратная связь при выполнении действий

**Файлы:**
- `luxvoice/actions/runner.py` - добавлены вызовы `speak()`
- `luxvoice/core/schema.py` - настройки `exec.voice_feedback` и `exec.speak_result`

**Описание:**
Теперь ассистент озвучивает:
- Название команды перед выполнением
- Название каждого действия в последовательности
- Результат выполнения (успех/ошибка)

**Пример:**
```
Пользователь: "Запусти браузер и открой ютуб"
Ассистент: "Выполняю: Запуск браузера и открытие сайта"
Ассистент: "Запуск программы"
Ассистент: "Открытие сайта"
Ассистент: "Готово"
```

**Настройки:**
- `exec.voice_feedback` - озвучивать действия (по умолчанию: True)
- `exec.speak_result` - озвучивать результат (по умолчанию: True)

## ✅ 3. Маршрутизация через локальный LM Studio/Ollama

**Файлы:**
- `luxvoice/ai/client.py` - провайдеры LM Studio и Ollama
- `luxvoice/actions/runner.py` - метод `_try_ai_route()`
- `luxvoice/core/schema.py` - настройка `aichat.route_unknown`

**Описание:**
Когда команда не распознана, система может отправить фразу в локальную нейросеть (LM Studio или Ollama) для анализа. Если нейросеть распознает намерение, команда выполняется автоматически.

**Как работает:**
1. Пользователь говорит фразу, которая не соответствует ни одной команде
2. Система проверяет, включён ли локальный AI провайдер
3. Фраза отправляется в нейросеть с промптом "Что хочет пользователь?"
4. Если нейросеть возвращает известную команду, она выполняется
5. Если нет - озвучивается ответ нейросети или стандартное "Не понял"

**Провайдеры:**
- **LM Studio:** `http://localhost:1234/v1`, без аутентификации
- **Ollama:** `http://localhost:11434/v1`, без аутентификации

**Настройки:**
- `aichat.route_unknown` - маршрутизировать неизвестные фразы через AI (по умолчанию: True)
- `ai.provider` - выбрать провайдер ("lmstudio" или "ollama")
- `ai.model` - название модели (например, "llama3.1", "mistral", "phi3")

**Пример использования:**
```
Пользователь: "Сделай скрин экрана и сохрани"
(Команда не найдена напрямую)
→ Отправка в LM Studio
→ Нейросеть: "Пользователь хочет сделать снимок экрана"
→ Система: "Выполняю: Снимок экрана"
```

## 🚀 Как использовать новые функции

### 1. Настройка паузы тишины
```
Настройки → Голосовой ввод → Распознавание речи → Пауза тишины
Установите значение от 0.3 до 5.0 секунд
```

### 2. Включение голосовой обратной связи
```
Настройки → Выполнение → Голосовая обратная связь
Включите для озвучивания действий и результатов
```

### 3. Настройка локального AI
```
1. Установите LM Studio или Ollama
2. Запустите локальный сервер
3. Настройки → AI → Провайдер → LM Studio / Ollama
4. Настройки → AI → Модель → выберите модель
5. Настройки → AI чат → Маршрутизация неизвестных фраз → Включить
```

### 4. Использование новых команд
Просто скажите:
- "Сделай громче" - увеличить громкость на 10%
- "Закрой окно" - закрыть активное окно
- "Сделай скриншот" - снимок экрана
- "Открой терминал" - запуск konsole
- И другие команды из списка выше
