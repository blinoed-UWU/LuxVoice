# 🎤 LuxVoice - Голосовой ассистент для управления компьютером

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform](https://img.shields.io/badge/platform-Linux%20|%20Windows-lightgrey)](#)

LuxVoice - мощный голосовой ассистент с поддержкой нейросетей для управления компьютером на русском языке. Работает офлайн (распознавание речи) и онлайн (ИИ-ответы).

## ✨ Возможности

### 🎯 Управление компьютером
- **Громкость**: "сделай громче", "тише", "без звука"
- **Окна**: "закрой окно", "сверни все окна", "разверни на весь экран"
- **Запуск программ**: "открой хром", "запусти steam", "открой проводник"
- **Система**: "выключи компьютер", "перезагрузи", "заблокируй экран"
- **Скриншоты**: "сделай скриншот", "снимок экрана"

### 🤖 Интеграция с нейросетями
- **Локальные ИИ**: LM Studio, Ollama (работает без интернета)
- **Облачные ИИ**: OpenAI, Anthropic, Google Gemini
- **Умные ответы**: задавайте вопросы, получайте объяснения
- **Генерация текста**: "напиши письмо", "составь список"

### 🎤 Голосовое управление
- **Распознавание речи**: Vosk (офлайн, русский язык)
- **Активация по слову**: "Джарвис" (настраивается)
- **Естественные команды**: говорите как обычно, не нужно зубрить фразы
- **Синтез речи**: RHVoice, eSpeak, edge-tts

### 🛠️ Дополнительные функции
- **Буфер обмена**: "скопируй текст", "вставь из буфера"
- **Эмуляция ввода**: нажатие клавиш, клики мышью
- **Управление питанием**: выключение, сон, гибернация
- **Расширяемость**: создавайте свои команды через JSON

## 📦 Установка

### Требования

- **Python**: 3.10+
- **ОС**: Linux (X11/Wayland) или Windows 10/11

**Linux**:
- python-evdev - виртуальный ввод (uinput)

**Windows**:
- pyautogui - эмуляция клавиатуры/мыши
- pygetwindow - управление окнами
- pycaw - управление громкостью
- pyperclip - буфер обмена

## 🔧 Настройка

### Конфигурация

Все настройки хранятся в `~/.config/luxvoice/settings.json` (Linux) или `%APPDATA%\LuxVoice\settings.json` (Windows).

Основные параметры:

```json
{
  "stt.enabled": true,
  "stt.wake_word": "джарвис",
  "ai.enabled": true,
  "ai.provider": "lmstudio",
  "ai.base_url": "http://localhost:1234/v1",
  "tts.enabled": true,
  "tts.engine": "edge-tts",
  "tts.voice": "ru-RU-DmitryNeural"
}
```

### Графический интерфейс

Запустите LuxVoice и откройте **Настройки** через иконку в трее.

Доступные разделы:
- **Общие**: автозапуск, язык, горячие клавиши
- **Голосовой ввод**: устройство микрофона, wake word, таймаут
- **ИИ-провайдер**: выбор нейросети, API ключи, проверка подключения
- **Озвучка**: голос, скорость, громкость
- **Команды**: управление пользовательскими командами
- **Безопасность**: подтверждения опасных действий

## 🤖 Настройка нейросети

### Вариант 1: LM Studio (локальная, бесплатно)

1. Скачайте [LM Studio](https://lmstudio.ai/)
2. Установите и запустите
3. Скачайте модель (рекомендуется: `qwen2.5-7b-instruct-q4_k_m`)
4. Включите **Local Server** (порт 1234)
5. В LuxVoice:
   - Настройки → ИИ-провайдер
   - Провайдер: **LM Studio**
   - Нажмите "Проверить подключение"

**Преимущества**: работает офлайн, бесплатно, приватно

### Вариант 2: OpenAI (облачная)

1. Получите API ключ на [platform.openai.com](https://platform.openai.com/api-keys)
2. В LuxVoice:
   - Настройки → ИИ-провайдер
   - Провайдер: **OpenAI**
   - Вставьте API ключ
   - Модель: `gpt-4o-mini` (дешевле) или `gpt-4o` (лучше)

**Преимущества**: высокое качество, не требует мощного ПК

### Вариант 3: Ollama (локальная)

```bash
# Установка
curl -fsSL https://ollama.com/install.sh | sh

# Запуск сервера
ollama serve

# Скачивание модели
ollama pull llama3.1
```

В LuxVoice:
- Провайдер: **Ollama**
- Модель: `llama3.1`

### Кроссплатформенность

LuxVoice использует абстрактный интерфейс (`sysint/base.py`) для системных операций:

```python
class PlatformInterface(ABC):
    @abstractmethod
    def get_volume(self) -> int: ...
    
    @abstractmethod
    def press_key(self, key: str) -> bool: ...
    
    @abstractmethod
    def close_window(self) -> bool: ...
```

Для каждой платформы есть своя реализация:
- **Linux**: uinput, pactl, wmctrl
- **Windows**: pyautogui, pycaw, pygetwindow

## 📝 Создание своих команд

Команды хранятся в `~/.config/luxvoice/commands.json`:

```json
{
  "commands": [
    {
      "id": "my_command",
      "phrases": ["открой мой проект", "запусти проект"],
      "actions": [
        {
          "type": "shell",
          "params": {"command": "cd ~/projects && code ."}
        },
        {
          "type": "speak",
          "params": {"text": "Открываю ваш проект"}
        }
      ]
    }
  ]
}
```

**Типы действий**:
- `speak` - озвучить текст
- `shell` - выполнить команду оболочки
- `launch_app` - запустить программу
- `press_key` - нажать клавишу
- `set_volume` - установить громкость
- `close_window` - закрыть окно
- и многие другие...

## 🐛 Известные проблемы

### Linux
- **Wayland**: некоторые действия требуют прав на uinput
- **PulseAudio**: может потребоваться pactl для управления громкостью

### Windows
- **UWP-приложения**: не все приложения из Microsoft Store поддерживаются
- **Антивирусы**: могут блокировать эмуляцию ввода (добавьте в исключения)
- **Права администратора**: требуются для некоторых операций
