# LuxVoice

Голосовой ассистент для Linux: управляет компьютером голосом и текстом,
понимает команды, выполняет сценарии, отвечает голосом, работает с
нейросетями и Telegram.

Разработан под CachyOS (Arch) с KDE Plasma 6 на Wayland. Работает и на
других современных дистрибутивах Linux.

---

## Что умеет

**Голосовое управление**
Слушает микрофон, распознаёт речь локально (Vosk) и выполняет команды.
Скажите «сделай громче», «открой ютуб», «сверни все окна» — ассистент
сделает это. Ничего не отправляется в интернет: распознавание идёт на
вашем компьютере.

**117 готовых команд**
Паки для браузера, YouTube, музыки, окна, системы, текста, Telegram,
Minecraft, работы, программирования, скриншотов и питания. Устанавливаются
одним нажатием и дальше живут как обычные команды — их можно менять.

**Редактор команд**
Дерево «коллекция → папка → команда», любое количество фраз на команду,
75 типов действий в 10 группах. Сценарий собирается из шагов: открой сайт →
подожди 3 секунды → нажми клавиши → скажи фразу. Порядок меняется стрелками.

**Связки команд**
«Открой ютуб и сделай тише» — одно предложение, две команды. Разделители
настраиваются: «и», «затем», «потом».

**Озвучка ответов**
Piper, RHVoice, eSpeak NG или облачные голоса. Шесть характеров: дворецкий,
дружелюбный, краткий, геймерский, спокойный, без озвучки. Микрофон
автоматически замолкает, пока ассистент говорит.

**Нейросеть**
13 провайдеров: OpenAI, Anthropic, Gemini, Grok, DeepSeek, YandexGPT,
GigaChat, OpenRouter, ProxyAPI, AITunnel, Ollama, LM Studio и свой сервер.
Поиск в интернете, создание файлов, чтение экрана. Может выполнять команды
по смыслу запроса.

**Telegram-бот**
Управление компьютером из мессенджера: команды кнопками, состояние системы,
голосовые сообщения, подтверждение опасных действий. Реагирует только на вас.

**Аватар**
Живой индикатор поверх окон: пульсирует, когда слушает, меняет цвет, когда
думает или говорит. Можно перетаскивать, можно сделать «сквозным» для мыши.

**История и защита**
Вся история выполненных команд в базе. Запрещённые опасные команды,
подтверждение перед необратимыми действиями, ограничение частоты запуска,
аварийная остановка.

## Установка

```bash
cd ~/Проекты/LuxVoice
./install.sh
```

Скрипт проверит Python, создаст окружение, поставит библиотеки, загрузит
модель распознавания и русские голоса, настроит ярлык и автозапуск.
Он сам скажет, что осталось сделать вручную.

**Один шаг требует вашего участия:** доступ к управлению компьютером.
Без него работают все команды, кроме нажатий клавиш и мыши.

```bash
sudo usermod -aG input $USER
```

Затем выйдите из системы и войдите заново. Это безопаснее, чем запускать
программу от администратора.

### Ручная установка

```bash
python3 -m venv --system-site-packages .venv
.venv/bin/pip install numpy requests pyyaml psutil sounddevice vosk

# Системные программы
sudo pacman -S python-pyqt6 pipewire wireplumber libnotify ffmpeg \
               spectacle wl-clipboard

# Необязательно, но улучшает качество
sudo pacman -S rhvoice rhvoice-language-russian espeak-ng brightnessctl
```

## Запуск

```bash
./run.sh                      # графический интерфейс
./run.sh --headless           # без интерфейса, только слушать
./run.sh --diagnose           # проверить компоненты
./run.sh --command "сделай громче"    # выполнить одну команду
./run.sh --install-model en   # загрузить английскую модель
```

Программа есть в меню приложений — значок **LuxVoice**.

При закрытии окна программа остаётся работать в области уведомлений и
продолжает слушать микрофон. Полный выход — через значок в трее.
Это поведение отключается в настройках.

## Как пользоваться

### Первый запуск

1. Откройте **Настройки → Голосовой ввод**. Выберите микрофон, нажмите
   **Проверить микрофон** в боковом меню.
2. Нажмите круглую кнопку микрофона в шапке. Скажите «сделай громче» —
   должна появиться надпись «Услышано».
3. Откройте **Дополнения**, установите нужные паки команд.
4. Откройте **Редактор команд**, посмотрите, что установилось, измените
   фразы под себя.

### Режим обращения

Включите **Режим обращения** в шапке — тогда команды срабатывают только
после имени: «люкс, сделай громче». Это спасает от случайных срабатываний
на разговоры. Имя и его варианты задаются в настройках.

### Своя команда за минуту

1. **Редактор команд → + Команда** (нужно выбрать папку в дереве).
2. Впишите название: «Открыть почту».
3. Добавьте фразы: «открой почту», «проверь почту».
4. Группа **Запуск → Открыть программу**. Выберите программу.
5. **Проверить команду** — убедитесь, что работает.

### Сценарий из нескольких шагов

Добавьте шаги по порядку:

| Шаг | Действие | Настройка |
|-----|----------|-----------|
| 1 | Открыть сайт | `https://music.yandex.ru` |
| 2 | Пауза | 4 секунды |
| 3 | Нажать клавиши | `space` |
| 4 | Произнести фразу | «Включаю музыку» |

### Связка из двух команд

В карточке обеих команд включите **Можно связывать с другими командами**.
После этого «открой ютуб и сделай тише» выполнит обе по порядку.

### Нейросеть

**Настройки → ИИ-провайдер**: выберите сервис, вставьте ключ, нажмите
**Проверить подключение**. Ключ не отображается в списке настроек и не
попадает в файлы экспорта.

Для работы без интернета: установите **Ollama** (`sudo pacman -S ollama`),
запустите её и выберите провайдером — ключ не нужен.

### Telegram

1. В Telegram напишите **@BotFather** команду `/newbot`, получите токен.
2. Узнайте свой ID у **@userinfobot**.
3. **Настройки → Дополнения**: включите Telegram, вставьте токен и ID.
4. Напишите своему боту `/menu`.

Опасные команды (выключение, перезагрузка, удаление) из Telegram запрещены,
пока вы отдельно не разрешите их в настройках.

## Настройки

225 настроек в 14 разделах. В окне есть три уровня: **обычные**,
**дополнительные** и **экспертные** — включаются кнопкой внизу слева.
Плюс поиск по всем настройкам сразу.

| Раздел | Что настраивается |
|--------|-------------------|
| Общие | Запуск, автозакрытие, приветствие, горячие клавиши |
| Голосовой ввод | Микрофон, движок, чувствительность, фильтр шума, режим обращения |
| Выполнение команд | Порог совпадения, связки, подтверждения, ограничения |
| Озвучка | Движок, голос, скорость, громкость, характер |
| ИИ-провайдер | Сервис, ключ, модель, температура, таймауты |
| Нейросеть | Поведение чата, системная подсказка, поиск, файлы |
| Интерфейс | Тема, акцент, масштаб, аватар, трей, уведомления |
| Поиск файлов | Где искать, что пропускать, глубина обхода |
| Действия и безопасность | Разрешения, опасные команды, карантин |
| Дополнения | Паки, Telegram, автозагрузка моделей |
| Производительность | Потоки, кэш, задержки распознавания |
| Приватность | Что хранить, автоочистка, офлайн-режим |
| Обновления | Проверка версий, канал, автоматика |
| Дополнительно | Отладка, журналы, сброс |

Значения применяются сразу — перезапуск нужен только для трёх настроек,
и окно об этом честно предупреждает.

## Файлы

| Что | Где |
|-----|-----|
| Настройки | `~/.config/luxvoice/config.json` |
| Команды | `~/.local/share/luxvoice/commands.json` |
| История | `~/.local/share/luxvoice/history.db` |
| Модели распознавания | `~/.local/share/luxvoice/models/` |
| Голоса синтеза | `~/.local/share/luxvoice/voices/` |
| Журнал | `~/.local/state/luxvoice/logs/luxvoice.log` |

Копирование всей папки `~/.local/share/luxvoice` переносит команды и
историю на другой компьютер. Настройки экспортируются отдельно, секреты
в экспорт не попадают.

## Если что-то не работает

Сначала всегда:

```bash
./run.sh --diagnose
```

Отчёт покажет, что именно не готово, и что с этим делать.

**Микрофон не слышит.** Настройки → Голосовой ввод → выберите устройство
вручную. Проверьте `pactl list short sources` — если устройств нет, проблема
в звуковой подсистеме, а не в ассистенте.

**Команды с клавишами не работают.** Нет доступа к `/dev/uinput`:
```bash
sudo usermod -aG input $USER   # затем выйти и войти заново
```

**Ассистент не слышит вас, когда играет музыка.** Увеличьте
**Чувствительность** и включите **Фильтр шума** в разделе «Голосовой ввод».

**Команда срабатывает не всегда.** Добавьте варианты фраз в карточку
команды — на каждый, как вы её реально произносите. Понизьте **Порог
совпадения** до 65–70 в разделе «Выполнение команд».

**Команда срабатывает слишком часто.** Поднимите порог до 80–85, включите
**Режим обращения**, добавьте **Паузу между запусками** в карточке команды.

**Нейросеть отвечает ошибкой 401.** Ключ вставлен не полностью или не
подходит к выбранному сервису. Кнопка с глазом в поле ключа покажет, что
именно вставлено.

**Telegram-бот не запускается.** Проверьте, что бот не заблокирован у
провайдера: `curl https://api.telegram.org`. Если соединения нет, нужен VPN.

**Нет русского голоса.** `sudo pacman -S rhvoice rhvoice-language-russian`
или `./run.sh --install-model ru` для повторной загрузки голосов Piper.

**Программа не появилась в меню.** `./run.sh` → Настройки → Дополнительно →
**Установить ярлык**, либо:
```bash
.venv/bin/python -m luxvoice.sysint.integration --install
```

## Устройство проекта

```
luxvoice/
├── core/            Ядро: настройки (225), модель команд, хранилище,
│                    сопоставление фраз, история, шина событий, перевод
├── sysint/          Система: uinput, окна KWin, PipeWire, буфер обмена,
│                    поиск программ, питание, интеграция
├── stt/             Распознавание: Vosk, Whisper, облако, захват звука,
│                    обработка сигнала на numpy
├── tts/             Синтез: Piper, RHVoice, eSpeak, облачные голоса
├── actions/         75 действий, исполнитель, исполнитель сценариев
├── packs/           12 паков, 117 команд
├── ai/              13 провайдеров нейросетей, поиск, файлы, экран
├── plugins/         Telegram-бот, аватар
└── ui/              Интерфейс: главное окно, редактор команд,
                     окно настроек, тема
```

**Ключевые решения**

*Настройки описаны в одном месте.* Схема (`core/schema.py`) содержит тип,
подпись, подсказку и границы каждой настройки. Из неё строится окно
настроек целиком. Добавили настройку в схему — поле появилось в интерфейсе.

*Подсистемы не знают друг о друге.* Распознавание, выполнение и озвучка
связаны шиной событий. Поэтому программу можно запустить без интерфейса
(`--headless`), и она работает так же.

*Фразы ищутся по словарю, а не перебором.* Обратный индекс слов, а не
сравнение со всеми 247 фразами. Поэтому отклик не зависит от количества
команд.

*Результат действия — понятный отчёт.* Каждый шаг возвращает, что
случилось. Это видно в истории, в Telegram и в редакторе.

## Совместимость

| Компонент | Состояние |
|-----------|-----------|
| KDE Plasma 6 + Wayland | Полностью поддерживается |
| GNOME / Wayland | Работает, окна через D-Bus |
| X11 | Работает |
| Python 3.10–3.14 | Поддерживается |
| PipeWire | Да |
| PulseAudio | Да, через pactl |
| Системы без systemd | Ограниченно |

Требуется Python 3.10+. На Python 3.13 и новее стандартный модуль `audioop`
удалён, а `webrtcvad` не работает — поэтому обработка сигнала написана
собственно на numpy и от них не зависит.
